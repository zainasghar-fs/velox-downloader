01 Overview

Vantload Downloader — Browser Companion is a Chrome extension that hands downloads and videos from your browser to the Vantload Downloader desktop app on your own Windows PC. It has one job: catch a URL, and pass it to an app already running on your computer. It is not a service, has no backend, and no server operated by the developer is involved anywhere in that path.

02 What the extension can see

The extension reads two kinds of information, only at the moment they're needed:

  • Download URLs — when Chrome starts a download, the extension reads that download's URL and suggested filename so it can offer it to Vantload Downloader.
  • Video source URLs — the content script looks for <video> elements on the page you're viewing, so it can show a "Download this video" button. It reads the video's source URL only when you click that button — it does not read surrounding page text, forms, or any other content.
None of this leaves your computer. Both kinds of URL are sent only to the Vantload Downloader app running locally on your own machine, over Chrome's Native Messaging protocol — a local, direct channel between the extension and a desktop app you installed. Nothing is transmitted to the developer, to analytics services, or to any server on the internet.

03 What it stores

The extension keeps exactly one value in chrome.storage.local: whether you've switched it on or off from the popup. That's the entire contents of its storage — no history of downloads, no browsing activity, no video URLs are retained after they're handed off.

04 Why each permission exists

downloads

Detects a download you start in Chrome, and — once handed off successfully — cancels Chrome's own copy so the file isn't saved twice.

nativeMessaging

The only channel the extension uses to talk to the Vantload Downloader app installed on your computer.

storage

Remembers the single on/off toggle described above.

host: <all_urls>

Lets the "Download this video" button appear on whichever site you're actually watching a video on — videos can live on any domain, so this can't be narrowed to a fixed list of sites.

05 What it never does

✕ Sell or share your data with anyone
✕ Run ads or ad tracking
✕ Use analytics or telemetry
✕ Send anything to a remote server
✕ Read page content beyond video elements
✕ Store download history or file contents

06 Third parties

None. The extension does not integrate any third-party SDK, analytics library, or remote API. The only other software it communicates with is the Vantload Downloader desktop app, which is also built by the same developer and runs entirely on your own computer.

07 Children's privacy

Vantload Downloader — Browser Companion is a general-purpose utility not directed at children, and it does not knowingly collect data from anyone, of any age — see Overview above.
